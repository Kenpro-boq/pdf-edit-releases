# Onepim PDF Editor — Releases

Installer and auto-update files for **Onepim PDF Editor** (Windows, 64-bit).

- Download the latest `Onepim.PDF.Editor_x.y.z_x64-setup.exe` from the **Releases** page.
- The program checks this repository for new versions automatically (`latest.json`).
- Opening the program's full features requires a license code issued by KENDECOR DEVELOPMENT CO., LTD.

This repository contains release files only. No source code.
